Why this matters

FERC Order 1920 requires utilities to plan together.

Neighboring utilities have historically planned in isolation, leading to duplicated mobilizations, conflicting outages and delays. GridLock turns public filings into a shared picture — before the first crew rolls.

Public data sources

GridLock continuously ingests public planning data, normalizes it into one schema with real geometry and dates, then runs overlap detection on every change.

01

Ingest

Pull filings, GIS layers and capital-plan PDFs from FERC, SERTP, state PSCs and HIFLD.

02

Normalize

LLM extraction turns PDFs into rows; routes are geocoded and snapped to HIFLD corridors.

03

Detect

Segment-level proximity + schedule-window overlap, scored and ranked per pair.

04

Coordinate

Notify both planning teams with a shared brief and suggested resource-sharing plan.

How overlap detection works

Runs in your browser on every threshold change — no black box.

// 1. Spatial — min distance between any two route segments (km)
d = min( segDist(ai, bj) ) // 0 if routes cross
// 2. Temporal — overlap or gap between build windows (days)
overlap = max(0, min(endA, endB) − max(startA, startB))
gap     = max(0, max(startA, startB) − min(endA, endB))
// 3. Flag
SPACE+TIME if d ≤ R and gap ≤ W
PROXIMITY if d ≤ R (same corridor, different season)
SCHEDULE if overlap > 0 and d ≤ 3R (shared labor pool)
// 4. Score 0–100
score = 50 + 50·(0.6·(1 − d/R) + 0.4·st)
